#  Desafío Jaguar
Aplicacion que se uso para una competencia escolar, en donde hubieron etapas de preguntas y etapas de busqueda de llaves. Con una funcionalidad de cronometro para que un docente vea el tablero de quien fue el ganador
_________________________________________________________
# Caracteristicas principales:
*Login intuitivo para docentes y estudiantes
![image](https://github.com/user-attachments/assets/29c01c55-4d57-4e21-b99d-b7b2b15c3f87)

*Interfaz de estudiante, consiste en 8 etapas dividadas en modulos de conocimiento y de busqueda de llave. Aqui mismo hicimos que se tome el tiempo de manera individual para subirla en la base de datos cuando el equipo acabe.
![image](https://github.com/user-attachments/assets/f9687539-f066-4547-9488-752840f7d387)
![image](https://github.com/user-attachments/assets/18f8788a-3e39-491c-a6fe-3c5c0a743160)
![image](https://github.com/user-attachments/assets/29978091-a208-46ed-941e-3024e40da549)
![image](https://github.com/user-attachments/assets/b322758d-16c5-4bf1-a1c5-b1b178ca0a86)

*Interfaz de administrador. Al finalizar los equipos el docente podra ver cuanto tiempo hizo cada equipo, en caso de ser necesario podra agregar tiempo de penalizacion a cada equipo. Tambien tendra la opcion de exportarlos para presentaciones.
![image](https://github.com/user-attachments/assets/19d00aef-0de7-437d-a5b1-f977635034c2)

# Tecnologias usadas
*Frontend:* React.js + Bootstrap +Electron
*Backend:* Node.js (AWS "Lambda")
*Base de datos:* PostgreSQL (AWS "Aurora and RDS")
